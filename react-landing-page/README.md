# React Landing Page Starter

A modern, responsive React frontend template built with **Vite**, **Tailwind CSS**, and **Lucide Icons**.

## Features

- ⚡️ **Vite** - Lightning-fast HMR and bundle speed.
- 🎨 **Tailwind CSS** - Modern utility-first styling.
- 🌓 **Dark / Light Mode** - Built-in smooth theme switching.
- 📱 **Fully Responsive** - Mobile, tablet, and desktop ready.
- 🧩 **Lucide Icons** - Clean, minimal SVG icons.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
